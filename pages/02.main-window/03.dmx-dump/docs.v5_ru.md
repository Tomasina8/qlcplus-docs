Функция **DMX Dump** считывает текущие значения выходных каналов и сохраняет их в виде *Ссцены** (Scene). Это самый быстрый способ создания сцены: настройте нужную световую картину вручную — с помощью инструментов каналов, окна просмотра значений DMX (DMX view) или панели Simple Desk, — а затем сохраните эти значения в функцию, которую можно будет вызвать в любой момент (кнопкой или другой функцией).

## Принцип работы

По мере того как вы вручную изменяете значения каналов, QLC+ отслеживает все затронутые вами каналы — эти значения называются **захваченными**. Именно они будут записаны в сцену при выполнении операции выгрузки.

Кнопка **Выгрузка значений DMX** находится на верхней панели инструментов (обозначена небольшим значком в виде кубика). Красный **индикатор** на кнопке показывает количество каналов, значения которых были захвачены в данный момент. Если на индикаторе отображается `0`, значит, ни один канал не был изменен и сохранять нечего.

Вы можете в любой момент очистить захваченные значения, не создавая сцену, — для этого воспользуйтесь функцией **Сбросить каналы** на правой панели (или сочетание клавиш **Ctrl+R**). Захваченные значения также автоматически сбрасываются в ряде случаев, например, при создании нового проекта.

> Кнопка `Выгрузка значений DMX` работает только тогда, когда разрешено редактирование функций.

## Запуск операции выгрузки

Открыть диалоговое окно сохранения можно двумя способами:

* **Нажать** кнопку `Выгрузка значений DMX` на панели инструментов.
* **Перетащить** кнопку `Выгрузка значений DMX` на функцию в `Диспетчере функций` (Function Manager). В этом случае данная функция будет автоматически выбрана в качестве целевой сцены для сохранения значений (см. ниже).

## Диалоговое окно выгрузки

Окно состоит из двух разделов.

### Целевая сцена

Выберите, куда будут сохранены захваченные значения:

* **Сохранить в новую сцену** (Dump to a new Scene) — создает новую сцену. В текстовом поле предлагается название по умолчанию (*Новая Сцена N*); вы можете изменить его на любое другое.
* **Сохранить в существующую сцену** (Dump to existing Scene) — добавляет захваченные значения в уже созданную ранее сцену. В качестве целевой сцены используется та, что в данный момент выбрана в Диспетчере функций; если ничего не выбрано, отображается надпись *(Ничего не выбрано)*. (При перетаскивании кнопки `Выгрузка значений DMX` на функцию этот вариант выбирается автоматически.)

### Каналы для сохранения

Выберите, какие из задействованных каналов следует сохранить:

* **Сохранить все доступные каналы** — сохраняются все каналы для всех Вселенных (Universes) и приборов (Fixtures), а не только те, которые вы изменяли. В диалоговом окне отображается, сколько вселенных и приборов при этом затрагивается. 
* **Сохранить только ненулевые значения** — (доступно при выборе предыдущего варианта) каналы со значением `0` игнорируются; таким образом, в сцену попадут только те каналы, которые фактически активны в данный момент.
* **Сохранить каналы выбранных приборов** — сохраняются только каналы тех приборов, которые выбраны в данный момент. Эта опция доступна, если у выбранных приборов есть измененные (активные) каналы.

#### Обнаруженные типы каналов

При сохранении каналов выбранных приборов в диалоговом окне отображается список обнаруженных **типов каналов** — например: яркости (Intensity), RGB/CMY/WAUV, цветовые макросы (Colour macros), гобо (Gobo), панорама (Pan), наклон (Tilt), скорость (Speed), затвор/стробоскоп (Shutter/Strobe), призма (Prism), луч (Beam), эффекты (Effect) и служебные функции (Maintenance). Рядом с каждым типом есть флажок, позволяющий включить его в сохраняемые данные или исключить из них. Отметьте только те типы каналов, которые должны войти в сцену — например, можно сохранить настройки цвета, исключив при этом интенсивность.

## Завершение

Подтвердите действие в диалоговом окне, чтобы создать новую сцену или обновить существующую, включив в нее выбранные вами каналы. Новая (или обновленная) сцена появится в `Менеджере функций` (Function Manager) — её можно будет редактировать, просматривать и запускать также как и любую другую функцию.
