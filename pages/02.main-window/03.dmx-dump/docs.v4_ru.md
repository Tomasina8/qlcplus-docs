Функция DMX Dump позволяет выгрузить текущие значения каналов DMX, передаваемых во Вселенные (Universes) в текущий момент времени. По сути, она делает `снимок` состояния DMX-каналов и сохраняет его для последующего использования.
С помощью выгрузки можно создать новую [Сцену (Scene)](/basics/glossary-and-concepts#scene) или перезаписать значения в уже существующей сцене. Сохраненную таким образом сцену также можно добавить в существующий [Чейзер (Chaser)](/basics/glossary-and-concepts#chaser), либо назначить на [кнопку](/virtual-console/button) или [фейдер (slider)](/virtual-console/slider) в виртуальной консоли (Virtual Console).

Обратите внимание:

*   Выбранные каналы/чейзеры запоминаются при повторном открытии этого окна.
*   Сохраняемые значения DMX действуют до применения общего мастер-регулятора (Grand Master).

При открытии окна DMX Dump доступны следующие опции:

| | |
| - | - |
| **Название сцены** | Позволяет задать имя для создаваемой сцены. Если имя не указано, будет присвоено название по умолчанию (например, `New Scene From Live`) с добавлением числового идентификатора. |
| ![](/basics/scene.png) **Сохранить в существующую сцену** | При нажатии на эту кнопку открывается окно выбора, в котором можно указать существующую сцену. Её содержимое будет перезаписано текущими значениями DMX.<br><br>***Примечание:*** Перезапись сцены выполняется без дополнительного подтверждения. Будьте внимательны: ошибочный выбор сцены может привести к потере данных.<br><br>После выбора сцены в окне выгрузки автоматически выполняются следующие действия:<br>*   Активируется опция `Сохранить выбранные каналы`<br>*   Дерево световых приборов обновляется: в нём будут отмечены только те каналы, которые входят в состав выбранной сцены. Если вы хотите перезаписать другие каналы, вы можете изменить их выбор вручную перед подтверждением операции.<br>
| **Выгрузить все каналы** | При выборе этой опции QLC+ сохраняет значения всех каналов для всех вселенных и всех световых приборов. Для наглядности отображается сводная информация: количество световых приборов и каналов, которые будут сохраняться. |
| **Выгрузить выбранные каналы** | При выборе этой опции становится доступной панель ниже, где можно точно указать, какие именно каналы должны быть сохранены. Каналы изображают дерево, сгруппированное по вселенным и световым приборам. |
| **Добавить в** | В этом разделе вам предлагается немедленно использовать вашу сцену в существующем виджете виртуальной консоли.<br>Варианты:<br><br>**Чейзер**: список содержит все чейзеры, присутствующие при открытии окна выгрузки. У каждого чейзера есть флажок, который, если он установлен, сообщает QLC+ о добавлении вновь созданной сцены к выбранным чейзерам.<br>Эта функция очень полезна при использовании [Cue Lists](/virtual-console/cue-list) на панели [Виртуальная консоль](/virtual-console), поскольку вновь созданная сцена появится в списке Cue List для немедленного использования во время живого выступления.<br>**Кнопка**: список содержит все имеющиеся в данный момент кнопки в пространстве вашей виртуальной консоли.<br>При выборе кнопки будут настроены на активацию/деактивацию только что снятой сцены. Вы увидите, что надпись кнопки изменится на `Сцена из прямого эфира...` и номер для ее идентификации.<br>***Примечание:*** Любая предыдущая функция, связанная с выбранными кнопками, будет перезаписана!<br>**Фейдер**: список содержит все ползунки, которые в настоящее время присутствуют в вашей виртуальной консоли.<br>Как и в случае с кнопками, все выбранные фейдеры будут настроены на управление только что сохраненной сценой.<br>***Примечание 1***: Чтобы работать с яркостью, ползунок должен находиться в **режиме воспроизведения** для сцены.<br>***Примечание 2***: Любая предыдущая функция, связанная с выбранными ползунками, будет перезаписана! |
| **Выгружать только ненулевые значения** | Эта опция указывает QLC+ сохранять только те каналы, значения которых **не** равны нулю.<br>Если вы понимаете, что делаете, это позволит сэкономить место в проекте и избежать конфликтов каналов с другими виджетами виртуальной консоли. |
