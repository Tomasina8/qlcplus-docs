DMX-монитор — это полезный инструмент для отслеживания значений, передаваемых во Вселенные (Universes). На экране отображается информация только о тех приборах, которые вам нужны. Параметры отображения в мониторе никак не влияют на реальную адресацию приборов — в конце концов, это всего лишь **монитор**.
В DMX-мониторе предусмотрено два режима отображения: **Каналы DMX** (DMX view) и **2D вид** (2D view).

Каналы DMX
--------

В режиме `Каналы DMX` отображаются все приборы проекта; каждый канал представлен в виде чисел и значков. По сути, данные каждого канала распределены по трем строкам:

*   Значок группы каналов
*   Номер канала
*   Значение канала

2D вид
-------

2D вид — это еще один способ отображения световых приборов вашего проекта. Вместо числовых значений здесь используется графическое представление, максимально приближенное к тому, как прибор будет выглядеть в реальности.

В настоящее время 2D-вид отображает:

*   Общий диммер (Master Dimmer)
*   Параметры R/G/B
*   Параметры C/M/Y
*   Цветовые колеса (если они содержат значения цвета RGB; двухцветные значения не поддерживаются)
*   Шторку (Shutter): она считается открытой, если в названии функции нет слов `close` (закрыть) или `blackout` (затемнение) — например, `Shutter Close`.

В режиме 2D-вида можно выбрать, какие приборы отображать, и задать их расположение в сетке, соответствующей размерам реальной сцены.
Сетка имитирует вид сцены спереди, однако вы можете использовать ее как универсальное рабочее пространство по своему усмотрению.
Графические элементы можно перемещать вручную, перетаскивая их по сетке. При нажатии на элемент открывается панель `Редактор приборов` (Monitor Fixture Editor), расположенная в правой части окна, где можно настроить его параметры.

### Редактор параметров световых приборов

При нажатии на световой прибор он подсвечивается желтым цветом, а в правой части окна открывается редактор параметров световых приборов (Monitor Fixture Item Editor).
Ниже перечислены параметры, доступные для настройки:

| | |
| - | - |
| **Горизонтальное положение** | Задает положение по оси X на сетке (в единицах измерения сетки) |
| **Вертикальное положение** | Задает положение по оси Y на сетке (в единицах измерения сетки) |
| **Поворот** | Задает угол поворота графического элемента, представляющего выбранное оборудование |
| **Цветовой фильтр** | Позволяет назначить цветовой фильтр для выбранного элемента оборудования. Это полезно для обычных диммируемых приборов с традиционными лампами, которые сами по себе не излучают цвет. Для светодиодных RGB-приборов эта функция не применяется. |
| ![](/basics/fileclose.png) | Сброс ранее установленного цветового фильтра |


### Отображение Панорамирования/Наклона (Pan/Tilt)

Панорамирование и Наклон представлены ​​схематично в виде цветных колец или дуг вокруг прибора. Фиолетовая дуга отображает угол поворота (PAN), а бирюзовая — угол наклона (TILT). Серые точки обозначают рабочие диапазоны PAN/TILT. Нулевая отметка (середина диапазона) находится в нижней части.

На приведенном ниже рисунке диапазон PAN составляет 660 градусов, а диапазон TILT — 300 градусов. Прибор находится в крайнем положении против часовой стрелки (-330°) по оси PAN, а по оси TILT — в положении -150°.
