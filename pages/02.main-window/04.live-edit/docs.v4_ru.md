Начиная с версии 4.5.0, в QLC+ появилась функция, позволяющая корректировать ваши [Функции](/basics/glossary-and-concepts#functions) непосредственно в [Режиме управления](/basics/glossary-and-concepts#modes) (Operate Mode).
Значок 'Редактирование вживую' ![](/basics/liveedit.png) расположен на верхней панели QLC+ рядом со значком [DMX Dump](../dmx-dump) ![](/basics/add_dump.png) и становится активным только после перехода в `Режим управления`.
При нажатии на значок 'Редактирование вживую' открывается панель [выбора функций](/function-manager/function-selection), где нужно выбрать функцию для редактирования.
После нажатия кнопки OK откроется соответствующий редактор для внесения изменений в выбранную функцию.
На данный момент для редактирования в реальном времени поддерживаются следующие типы функций:

*   ![](/basics/scene.png) [Сцена](/basics/glossary-and-concepts#scene) — открывает [Редактор сцен](/function-manager/scene-editor).
Обратите внимание: если вы редактируете сцену, которая в данный момент не запущена, редактор по умолчанию открывается в `скрытом режиме` (Blind mode). Это позволяет внести изменения, которые вступят в силу только при следующем запуске этой сцены. Если же сцена уже запущена, редактор по умолчанию откроется в режиме реального времени (live mode). 
*   ![](/basics/chaser.png) [Chaser](/basics/glossary-and-concepts#chaser) открывает [редактор Чейзеров](/function-manager/chaser-editor)
*   ![](/basics/efx.png) [EFX](/basics/glossary-and-concepts#efx) открывает [редактор Спецэффектов (EFX)](/function-manager/efx-editor)
*   ![](/basics/rgbmatrix.png) [RGB Matrix](/basics/glossary-and-concepts#rgbmatrix) открывает [редактор RGB-матриц](/function-manager/rgb-matrix-editor)

Типы функций, перечисленные в разделе [Выбор функций](/function-manager/function-selection), можно фильтровать с помощью соответствующих флажков в нижней части панели.
В верхней части панели также предусмотрена опция, позволяющая отображать только те функции, которые запущены в данный момент. 

Обратите внимание: если во время внесения изменений в реальном времени запущена другая функция, каналы с правилом HTP (Highest Takes Precedence — `наибольшее значение имеет приоритет`) в этой функции могут препятствовать отображению некоторых изменений на сцене.
