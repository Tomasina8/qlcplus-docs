Установка QLC+ довольно проста.
Просто перейдите на [страницу загрузки] (https://www.qlcplus.org/download) и загрузите версию для своей операционной системы.

## Windows

QLC+ на Windows поставляется как устанавливаемый exe-пакет. Просто дважды щелкните по файлу и следуйте показанным инструкциям.

Выберите вариант установки QLC+: в стандартном расположении (C:\QLC+) или в другой папке, например, C:\Program Files.

Для установки QLC+ не требуется никаких привилегий администратора, но если вы хотите связать . qxw (файлы проекта) и . qxf (файлы описания светового прибора) для открытия по клику, то  щелкните по файлу установки правой кнопкой мыши и запустите его с правами администратора.

**Обратите внимание, что версия 4.x. и 5.x. не могут сосуществовать в одной папке, поэтому если хотите установите обе, то ставьте их в разные папкаи.

## macOS

QLC+ на macOS поставляется в виде пакета DMG.

Просто дважды нажмите на него и запустите QLC+ напрямую. В ином случае вы можете перетаскивать его в папку приложения.

## Linux

Официальный пакет QLC+ для Linux выпускается как пакет Debian (.deb).

Для установки выполните следующие действия с терминала и папки, в которую вы загружаете пакет:
`
sudo apt install . /qlcplus_x.y.z. deb
`
Продвинутые пользователи, знакомые с зависимостями, могут рассмотреть использование расширенной команды `sudo dpkg -i qlcplus_x.y.z. deb`.
